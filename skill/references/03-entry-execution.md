# 入场与执行

## 技术结构
只看四件事：
1. 高低点：抬高 / 横盘 / 降低
2. 平台：突破位、前高、前低
3. 趋势：MA20/MA60方向及股价位置
4. 阶段：启动、主升、回踩、加速、破坏

优先级：高低点结构 > 平台/突破位 > MA20/MA60 > 量价 > 辅助指标。

## Setup
S1 启动/平台突破：板块启动或扩散；个股核心；突破重要平台；成交活跃度改善；上方仍有空间。

S2 首次高质量回踩【最高优先级】：
> 放量突破 → 缩量回踩 → 原压力转支撑 → 出现承接
要求板块未明显转弱、核心地位未破坏、关键结构仍在。

S3 二次确认：
> 突破 → 回踩不破 → 再次转强

S4 二波再启动：
> 第一波 → 调整/横盘 → 核心不破 → 板块重新增强 → 个股再次领先

默认回避：下降趋势猜底、箱体中部、高位连续加速、退潮后排、顶着重大压力开仓。

## 位置与量价
方向看多不等于现在能买。
检查：离支撑多远、离压力多近、是否连续加速、板块是否高潮、失效位是否过远。
量价只回答：上涨是否有真实成交确认；回调是否缩量并有承接；高位是否巨量滞涨/长上影/放量破位。

## 五道门
用户问“现在能买吗”时检查：
1. 方向：板块仍可交易？
2. 个股：仍为核心/强势股？
3. 结构：日线健康？
4. 触发：S1~S4是否出现？
5. 风险收益：失效清楚且第一目标有足够空间？

评级：A可执行；B接近触发；C值得跟踪但位置一般；D当前不做；BLOCK逻辑/风险否决。

## 失效与R/R
失效来自结构，不使用固定百分比。优先依据：突破位重新跌破、关键前低、平台下沿、MA20与结构同时破坏、个股与板块同步转弱。

```text
风险 = 买入价 - 结构失效位
收益 = 第一目标 - 买入价
R/R = 收益 ÷ 风险
```
参考：>=2.5较好；1.8~2.5可接受；1.3~1.8需极强确认；<1.3默认不新开仓。结合波动率和结构距离，不机械执行。

## 持仓与新开仓分开
同一只股票可以“不适合新买，但仍可持有”。
持仓看原逻辑是否失效、是否仍强于板块、是否形成更高低点、是否需上移保护位。
新开仓看Setup、触发、失效、第一目标和风险收益。
