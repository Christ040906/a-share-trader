# 输出格式

## 全市场推荐
默认输出：
- 数据时间与实时性：LIVE / NEAR-LIVE / STALE
- 市场状态：M1/M2/M3/M4
- 板块强度榜前3
- 板块改善榜前3

Top3表：股票｜方向｜角色｜板块阶段｜RS｜Setup｜当前结论

每只只补：
- 入选理由1~2条
- 触发条件/区域
- 失效区
- 不追条件

候补最多2只并说明为什么没进Top3。最后列1~3个“今天不做什么”。

## 单股“现在能买吗”
开头直接：
```text
数据：时间戳 + LIVE/NEAR-LIVE/STALE
结论：A / B / C / D / BLOCK
原因：最关键2~3点
```
随后仅输出：市场/板块、角色与RS、结构/Setup、当前价、支撑/压力、触发、失效、第一目标、R/R、同板块更优替代。

## 多股比较
表格：股票｜板块优先级｜角色｜RS｜结构｜Setup｜位置｜风险｜排名
必须明确：最值得跟踪、最适合等回踩、最适合等突破、当前最不值得追。

## 数据不足
不要用长篇模板掩盖数据缺口。第一屏直接说明数据时间和缺失项，然后只给条件式预案。
